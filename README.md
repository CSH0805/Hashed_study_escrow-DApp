# 스테이블코인 에스크로(안전결제) 디앱

구매자가 맡긴 스테이블코인을 **중개 회사 대신 스마트 컨트랙트가 보관**하다가, 거래가 끝나면 규칙에 따라 판매자나 구매자에게 보내 주는 안전결제 서비스입니다.

블록체인 기초(비트코인·이더리움)를 공부한 뒤, **디앱이 어떻게 구성되고 동작하는지 직접 만들면서 익히기 위한 학습용 프로젝트**입니다. 내 컴퓨터의 로컬 블록체인(Anvil)에서 개발하고, **이더리움 공개 테스트넷 Sepolia에 배포**했습니다.

> ⚠️ 학습용 코드입니다. 메인넷에는 배포하지 않으며, 감사(audit)를 받지 않았으므로 실제 자산에 사용하지 마세요. Sepolia의 ETH와 mUSD는 돈 가치가 없는 테스트용입니다.

## 왜 에스크로인가

중고 거래에서 구매자는 "돈을 먼저 보냈는데 물건이 안 오면?", 판매자는 "물건을 보냈는데 돈을 안 주면?"을 걱정합니다. 그래서 보통은 **안전결제 회사**가 중간에서 돈을 맡아 둡니다.

이 디앱은 그 회사의 역할을 **스마트 컨트랙트(코드)** 가 대신합니다.

- 돈은 컨트랙트가 보관하고, **배포한 사람을 포함해 누구도 임의로 꺼낼 수 없습니다.**
- 규칙은 코드로 공개되어 있어 **누구나 확인할 수 있고, 배포 후에는 바뀌지 않습니다.**
- 사용자는 회사를 믿는 대신 **코드를 믿으면 됩니다.**

## 거래는 이렇게 흘러갑니다

```
① 구매자가 거래를 만들고 돈을 맡김  ──▶  [진행중] 돈이 컨트랙트에 묶임
                                          │
        ┌─────────────────────────────────┼──────────────────────────────────┐
        ▼                                 ▼                                  ▼
② 구매자가 "구매확정"            ② 판매자가 "거래 취소"           ② 마감이 지나도 확정이 없으면
   → 판매자에게 지급                → 구매자에게 환불                 판매자가 "자동 지급 받기"
   [지급완료]                       [환불완료]                        → 판매자에게 지급 [지급완료]
```

- 구매자가 연락이 끊겨도, **마감이 지나면** 판매자의 돈이 영원히 묶이지 않습니다.
- 구매자가 마음대로 환불받을 수는 없고, **환불은 판매자만** 할 수 있습니다. 물건만 받고 취소하는 악용을 막기 위해서입니다.
- 한 번 끝난 거래는 다시 처리할 수 없습니다.

## 화면에서 할 수 있는 것

| 기능 | 설명 |
|---|---|
| 지갑 연결 | MetaMask로 연결하고, 내 주소와 mUSD 잔고를 확인 |
| 테스트 코인 받기 | 버튼 한 번에 테스트용 스테이블코인 1,000 mUSD 지급 (실제 가치 없음) |
| 거래 만들기 | 판매자 주소·금액·마감일·설명을 입력하고 돈을 맡김. **두 가지 방식** 중 선택 가능 (아래 참고) |
| 내 거래 목록 | "내가 구매자인 거래" / "내가 판매자인 거래" 탭 |
| 거래 상세 | 내 역할과 거래 상태에 맞는 버튼만 표시 (구매확정 / 거래 취소 / 자동 지급 받기) |
| 거래 내역 | 거래가 언제, 몇 번 블록에서, 누구의 서명으로, 가스비 얼마에 처리됐는지 시간순으로 표시 |
| 진행 안내 | 서명 대기·전송·성공·실패(서명 거절 포함)를 한국어로 안내 |

### 거래를 만드는 두 가지 방식

| | 방식 A · approve | 방식 B · permit |
|---|---|---|
| 비유 | 은행 창구에 가서 "안전결제 회사가 내 돈 100 빼 가도 돼요"라고 신청한 뒤, 안전결제 창구에 다시 가서 거래 등록 | 집에서 동의서에 **서명만** 해서 안전결제 창구에 들고 가면, 회사가 은행에 대신 제출 |
| MetaMask 확인 창 | 트랜잭션 확인 2번 | 서명 요청 1번(가스 없음) + 트랜잭션 확인 1번 |
| 가스비 | 더 많음 | 더 적음 |

> **트랜잭션 ≠ 거래**: 여기서 "트랜잭션"은 사고파는 거래가 아니라, **블록체인 장부를 바꾸는 요청 한 건**(MetaMask 확인 창 한 번)을 말합니다. 거래 하나를 끝내는 데에는 트랜잭션이 여러 번 필요합니다.
