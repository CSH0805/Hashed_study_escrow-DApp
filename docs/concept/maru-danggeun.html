마루 당근 구상도

동네 중고거래의 "안전결제"를 마루 테스트넷 위 에스크로 컨트랙트로 처리하는 앱. 지금 만든 스테이블코인 에스크로 디앱을 출발점으로, 원화 스테이블코인(OKRW)과 이메일 로그인 지갑을 붙이는 구상입니다.

현장실습생 개인 학습용 구상이며, 회사 내부 자료 없이 공개된 문서와 발표만 근거로 했습니다. 회사의 실제 계획과 다를 수 있습니다.

출발점

지금 만든 것과 목표

지금: 스테이블코인 에스크로 디앱

  • Anvil · Sepolia에서 동작
  • 직접 만든 테스트 토큰 MockUSD (ERC-20, 6자리)
  • MetaMask로 연결, 가스는 ETH
  • approve + 예치 2번, 또는 permit 서명 + 예치
  • 화면: 당근형 UI로 변경 완료 (기능은 그대로)

목표: 마루 당근

  • 마루 테스트넷 chainId 450815
  • 체인 기본 화폐인 원화 OKRW로 결제
  • 이메일·카카오 로그인 지갑, 수수료 대납
  • 예치는 서명 1번 (승인 단계 없음)
  • 판매글·채팅은 일반 서버, 돈의 흐름만 체인

구조

무엇이 어디에서 돌아가나

핵심 원칙은 돈과 거래 상태만 체인에, 나머지는 서버에입니다. 판매글 사진이나 채팅을 체인에 올리면 비싸고 느리며, 개인정보가 영구히 공개됩니다.

거래 흐름

중고 키보드 한 건이 거래되는 과정

  1. 판매자가 판매글 등록사진, 가격 30,000 OKRW, 동네. 서버 DB에만 저장
    서버
  2. 구매자가 채팅으로 약속만날 장소와 시간 확정. 채팅도 서버
    서버
  3. 구매자가 "안전결제" 누름판매자 주소, 금액, 마감(예: 약속 다음 날)을 채운 예치 화면. 지금 만든 "안전결제 만들기"와 같은 자리
    서명 1번
  4. OKRW가 에스크로에 보관됨createDeal{value: 30,000 OKRW}. 네이티브 화폐라 approve가 필요 없고, 수수료는 Paymaster가 대납
    체인
  5. 직거래로 물건 확인판매자 화면에는 "결제 완료, 보관 중" 표시. 판매자는 돈이 실제로 맡겨진 걸 체인에서 확인
    오프라인
  6. 구매자가 구매확정release → 판매자에게 OKRW 지급. 거래 완료 기록이 매너 정보의 근거가 됨
    체인
  7. 예외: 취소 또는 연락 두절판매자 취소 시 refund로 환불, 구매자가 확정을 안 하면 마감 후 판매자가 claimAfterDeadline
    체인

진행 순서

단계별 로드맵

완료

에스크로 디앱 + 당근형 화면

컨트랙트 41개 테스트 통과, Anvil·Sepolia 동작, UI 변경 완료.

1단계

마루 테스트넷에 그대로 배포

MetaMask로 마루 체인 연결, faucet에서 OKRW 받아 배포. 체인만 바꾸고 MockUSD 그대로 써서 마루에서 돌아가는지 먼저 확인.

2단계

OKRW 네이티브 에스크로

컨트랙트를 payable로 바꾸고 테스트 다시 작성. 화면에서 승인 단계 제거.

3단계

이메일 로그인 지갑 + 수수료 대납

임베디드 지갑 SDK로 MetaMask 없이 사용. 앱 등록(테넌트)은 운영자 권한이 필요해 회사 확인 필요.

4단계

당근 기능: 판매글 · 채팅

간단한 서버와 DB. 판매글에서 바로 "안전결제"로 이어지게 연결.

5단계

규제와 신뢰

EAS로 판매자 본인 확인, PCL에 막힌 거래 안내, 분쟁 시 중재자(arbiter) 기능.

근거

확인된 것과 가정

공개 자료로 확인

  • 마루는 EVM 호환, Foundry·wagmi·viem 그대로 연결
  • 테스트넷 chainId 450815, RPC rpc-testnet.maroo.io
  • 기본 화폐 OKRW, 소수점 18자리
  • PCL(규제 레이어), EAS(증명), ERC-8004(에이전트)
  • Pouchi: 이메일 로그인 지갑, Paymaster, 정책 한도 (ERC-4337)

직접 확인해야 할 것

  • 컨트랙트 배포에 KYC가 필요한지
  • PCL이 컨트랙트 간 OKRW 이동을 어떻게 검사하는지
  • EAS 증명을 컨트랙트에서 읽는 정확한 방법
  • Pouchi 앱 등록 절차와 대납 비용 부담 주체
  • Solidity 0.8.30 컴파일 결과가 마루에서 그대로 도는지
